# AURELIA & CO.

Luxury Wedding Planning CRM

## Features

- Luxury Wedding Website
- Contact Form
- MongoDB Database
- Admin Dashboard
- JWT Authentication
- Inquiry Management
- Status Tracking
- Email Notifications

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT

Email:
- Nodemailer

## Installation

```bash
npm install
```

Backend:

```bash
cd backend
npm install
npm run dev
```

## Environment Variables

Create:

```env
PORT=
MONGODB_URI=
JWT_SECRET=
EMAIL_USER=
EMAIL_PASS=
```
